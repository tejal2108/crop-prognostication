# 🌾 Crop Prognostication

A machine learning-powered web application built with Django that predicts the most suitable and profitable crops for cultivation based on real-time weather and soil data.

## 📌 Overview

This system helps farmers make informed decisions about crop selection by analyzing key agricultural parameters such as temperature, soil type, rainfall, and market trends. It leverages machine learning models to forecast optimal crop options and supports both users and administrators through a responsive web interface.

## 🚀 Key Features

### 👨‍🌾 User Panel

* 🌱 **Crop Prediction**: Suggests the best crop based on environmental data.
* 🐛 **Pest Information**: Provides insights on common pests and preventive measures.
* 💰 **Market Prices**: Displays current commodity prices to help farmers make informed selling decisions.

### 🛠️ Admin Panel

* 🗂️ **Manage Government Schemes**: Add/update schemes for farmers' benefit.
* 📊 **Update Crop Prices**: Maintain real-time market data.
* 👥 **User Management**: View and manage registered users.

## 🧠 Machine Learning & Methodology

* ✅ Achieved **85% prediction accuracy** using Scikit-learn.
* 🧹 Data preprocessing and feature engineering using **Pandas** and **NumPy**.
* 🔍 Real-time weather data integrated using **REST APIs** to improve prediction quality.
* 🧪 Algorithms evaluated using accuracy, precision, recall, and F1-score.

## 🧰 Tech Stack

* **Frontend**: HTML, CSS, JavaScript
* **Backend**: Python, Django, REST APIs
* **ML Libraries**: Scikit-learn, Pandas, NumPy
* **IDE**: Visual Studio Code
